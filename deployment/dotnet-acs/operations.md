# .NET ACS 运维备忘录

状态：发布前模板，2026-09-26。待生产资源创建后补入非敏感 ID、告警接收人和实测恢复时间。按项目处理故障，避免误改既有 Java 应用与 SmsCore。

## 最小监控与定位

| 对象 | 监控 / 告警 | 第一层定位 |
|---|---|---|
| Front/Back API | `ready`、5xx、P95、重启、CPU、内存、登录/订单/回调失败 | 分辨 ALB 规则与证书、镜像、Secret 版本、数据库/Redis、可信转发头；401/403 要结合认证结果解释 |
| Worker | 心跳、最近成功时间、失败数、积压和最老待办、重复业务事件 | 比对旧服务自启状态、新旧 Pod、锁拥有者/租期、幂等记录、队列游标和首个到期任务 |
| 出口代理 | 服务健康、连接失败、拒绝数、并发、EIP 带宽、磁盘 | 区分 ACL 拒绝、供应商白名单、DNS/TLS、EIP 绑定及 Squid 日志；不把完整 URL/认证信息写日志 |
| ALB | Host 规则、证书、后端健康、5xx、LCU | 先按精确 Host 找对应 Ingress/Service/Pod；不要触碰共享监听器的其他 Host |
| 短信 | 项目路由、SmsCore 私网可达、发送结果与幂等记录 | 确认走 `172.27.182.18:3090`；SmsCore 供应商出口独立于新代理 ECS |

日志初始保留 7 天；业务审计继续在现有业务存储中。每个告警需标项目和角色，运维通知渠道在上线前验证可用。不要记录请求体、连接串、手机号、验证码、令牌或代理认证值。

## 典型故障动作

1. **API Ready 失败**：先检查镜像、Secret 版本、环境名与私网依赖；live 健康而 ready 失败时不要靠反复重启掩盖数据库或结构问题。检查连接池总数及只读连通性，必要时回滚成套镜像/配置。
2. **代理故障**：暂停或排队支付、退款、ERP 等依赖外呼的 Worker 任务或对应入口，确认待办不被重复消费。先区分 ECS、私网入口、Squid、DNS、EIP 和第三方白名单故障；同机恢复和换机恢复分别按[出口实施清单](egress-proxy.md)演练。换机时仅重绑 EIP 不会修复 Pod 指向旧 ECS 私网地址，还要切换稳定私网入口/配置并复核全部外呼。允许和拒绝用例均重新验收；结果不明的资金请求先查单。不得把流量临时转到 SmsCore ECS 或开放任意公网出口。
3. **外部回调异常**：核对正式 DNS、证书、ALB 精确 Host、签名和供应商回调地址；不能仅用集群内 curl 判定。对支付/退款状态不明请求先按业务单号查询平台结果，再按幂等规则处理。
4. **Worker 疑似重复**：立即停新调度，核查旧 systemd 自启与进程、新 Pod 实际退出、业务事件唯一约束、Redis 锁拥有者与租期。记录已经产生的外部副作用，先查询后恢复；不要盲删锁或批量补跑。
5. **经销商查询数据不一致**：停止新后台写入，按迁移映射核对门店数量、状态、坐标、图片、标签、管理员权限和新库增量；确认补偿方案前不回切写入口。

## 容量和费用

初始 13 个 Pod 共 9 CPU / 18 GiB。按本轮采用的 ACS 单价假设 `CPU ¥0.06/核时 + 内存 ¥0.03/GiB时`、每月 720 小时，算力为 `9×0.06×720 + 18×0.03×720 = ¥777.60/月`。这是**预算假设**，下单前应以账号实时计价及 ACS 规格规整结果校验。

2026-09-26 出口 ECS 规格加 40 GiB 云盘的只读报价约 `¥0.36291/小时`（约 `¥261.30/720小时`），是否包含镜像和折扣仍待核对。**目前该出口尚未采购，不计入已发生费用。** EIP 保有费用、实际出网流量、ACR 存储/构建、ALB LCU/流量、日志和监控、OSS、旧新并行期均另计；若单机 RTO 不可接受，还需另算高可用的第二台 ECS、第二枚 EIP 和内部稳定入口。沿用此前 Java 项目 `¥696～1162/月` 仅作为历史估算，不把它与本轮 Pod 算力简单相加冒充总成本承诺。

每月核对实际账单与 95 分位 CPU/内存、Pod 重启、ALB LCU、代理 EIP 出网、ACR 存储和日志量。若 Worker 空闲也不擅自休眠；先评估任务时刻与错过任务恢复规则。容量压测须在隔离环境进行，生产不故意制造数据库故障或破坏性负载。

## 周期性变更

- 证书续期前核对两组域名 Host 的证书覆盖及 ALB 扩展证书额度；先在新 ALB 指定 Host/SNI 验证，再改正式入口。
- 代理系统补丁/Squid 更新先保存包版本和配置哈希，安排外呼低峰维护，允许/拒绝用例均通过后恢复任务。
- 镜像/Secret/数据库结构更新必须形成一个版本组；回滚也按组执行。配置内容只通过受控系统管理，文档只存名称和版本。
- 每次扩大 ACR 凭据助手 Namespace 列表、代理目的域名或供应商 IP 白名单，都保存前后快照并复核现有 Java 工作负载与其他 Host 路由。
