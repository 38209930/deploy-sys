# .NET ACS 运维备忘录

状态：发布前模板，2026-09-26。待生产资源创建后补入非敏感 ID、告警接收人和实测恢复时间。按项目处理故障，避免误改既有 Java 应用与 SmsCore。

## 最小监控与定位

| 对象 | 监控 / 告警 | 第一层定位 |
|---|---|---|
| Front/Back API | `ready`、5xx、P95、重启、CPU、内存、登录/订单/回调失败 | 分辨 ALB 规则与证书、镜像、Secret 版本、数据库/Redis、可信转发头；401/403 要结合认证结果解释 |
| Worker | 心跳、最近成功时间、失败数、积压和最老待办、重复业务事件 | 比对旧服务自启状态、新旧 Pod、锁拥有者/租期、幂等记录、队列游标和首个到期任务 |
| 公共 NAT 出口 | NAT 状态、SNAT 连接失败、EIP 带宽、项目外呼失败率/P95/429 | 对照路由表关联、SNAT 命中来源、EIP 绑定、DNS/TLS、供应商白名单；NAT 不提供域名 ACL |
| ALB | Host 规则、证书、后端健康、5xx、LCU | 先按精确 Host 找对应 Ingress/Service/Pod；不要触碰共享监听器的其他 Host |
| 短信 | 项目路由、SmsCore 私网可达、发送结果与幂等记录 | 确认走 `172.27.182.18:3090`；SmsCore 供应商出口独立于新 NAT EIP，旧直连供应商通道必须停用 |

日志初始保留 7 天；业务审计继续在现有业务存储中。每个告警需标项目和角色，运维通知渠道在上线前验证可用。不要记录请求体、连接串、手机号、验证码或令牌。出口带宽持续 5 分钟超过 10 Mbps 上限的 70% 预警；达到 85% 且出现业务失败时处置。外呼 5 分钟内至少 20 次且失败率超过 5% 告警。

## 典型故障动作

1. **API Ready 失败**：先检查镜像、Secret 版本、环境名与私网依赖；live 健康而 ready 失败时不要靠反复重启掩盖数据库或结构问题。检查连接池总数及只读连通性，必要时回滚成套镜像/配置。
2. **NAT 出口故障**：暂停或排队支付、退款、ERP 等依赖外呼的 Worker 任务或对应入口，确认待办不被重复消费。按[出口手册](egress-nat.md)先查 NAT 状态、共享或自定义路由表、SNAT 来源、EIP 绑定和带宽，再查 DNS/TLS、供应商白名单与应用客户端。结果不明的资金请求先查单。单项目问题只回滚该项目，不能贸然撤销共享 SNAT；全网故障按批准的路由快照回滚并逐项复核 Java、SmsCore 与范围外来源。保留固定 EIP，不临时切到 SmsCore ECS 或新公网 IP。
3. **外部回调异常**：核对正式 DNS、证书、ALB 精确 Host、签名和供应商回调地址；不能仅用集群内 curl 判定。对支付/退款状态不明请求先按业务单号查询平台结果，再按幂等规则处理。
4. **Worker 疑似重复**：立即停新调度，核查旧 systemd 自启与进程、新 Pod 实际退出、业务事件唯一约束、Redis 锁拥有者与租期。记录已经产生的外部副作用，先查询后恢复；不要盲删锁或批量补跑。
5. **经销商查询数据不一致**：停止新后台写入，按迁移映射核对门店数量、状态、坐标、图片、标签、管理员权限和新库增量；确认补偿方案前不回切写入口。

## 容量和费用

初始 13 个 Pod 共 9 CPU / 18 GiB。按本轮采用的 ACS 单价假设 `CPU ¥0.06/核时 + 内存 ¥0.03/GiB时`、每月 720 小时，算力为 `9×0.06×720 + 18×0.03×720 = ¥777.60/月`。这是**预算假设**，下单前应以账号实时计价及 ACS 规格规整结果校验。

公网出口采用跨可用区 NAT + 一个 EIP，**目前均未采购，不计入已发生费用**。北京官方标价按 720 小时约 `0.23×720 + 0.02×720 = ¥180/月` 固定费；另加 NAT 双向处理 `¥0.23/GiB`、公网出流量约 `¥0.80/GiB`，以及 ACR 存储/构建、ALB LCU/流量、日志和监控、OSS、旧新并行期。实际按账号下单页与账单复核。首月 400 元预警、600 元升级复核，不自动断网。沿用此前 Java 项目 `¥696～1162/月` 仅作为历史估算，不把它与本轮 Pod 算力简单相加冒充总成本承诺。

每月核对实际账单与 95 分位 CPU/内存、Pod 重启、ALB LCU、NAT 双向处理量、EIP 出网、ACR 存储和日志量。若 Worker 空闲也不擅自休眠；先评估任务时刻与错过任务恢复规则。容量压测须在隔离环境进行，生产不故意制造数据库故障或破坏性负载。

## 周期性变更

- 证书续期前核对两组域名 Host 的证书覆盖及 ALB 扩展证书额度；先在新 ALB 指定 Host/SNI 验证，再改正式入口。
- 路由、SNAT 来源或 EIP 绑定变更前后均保存资源 ID、路由关联、受影响来源和 RequestId；低峰维护并复核范围外 vSwitch、全部 Java 与 SmsCore。
- 镜像/Secret/数据库结构更新必须形成一个版本组；回滚也按组执行。配置内容只通过受控系统管理，文档只存名称和版本。
- 每次扩大 ACR 凭据助手 Namespace 列表、SNAT 来源或供应商 IP 白名单，都保存前后快照并复核现有 Java 工作负载与其他 Host 路由。
