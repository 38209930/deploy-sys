# Apollo 后台前端合并分支

执行 `python3 scripts/sync-apollo-merge-menu.py` 安装本机菜单，刷新页面后选择 **阿波罗数据中台 → 合并分支 → prod**。该入口只处理 Apollo 的 `pc` 仓库，不执行 OSS 上传。

执行前，请在 `pc` 切到已提交的待发布开发分支或 `release`，保持工作区干净。脚本在临时目录拉取最新远端分支，依次执行：

1. 合入最新 `origin/master`（如待发布分支已有远端提交，也先同步）。
2. 使用 `npm ci --no-audit --no-fund` 安装锁定依赖，执行 `npm run build:prod`。
3. 合入最新 `origin/release`；若集成后源码不同，再次安装依赖并构建验证。
4. 将已验证的 release 快进合入 master；再次核对远端分支没有变化。
5. 原子推送 release、master 和待发布分支，核验远端提交；将本地待发布分支快进至最终集成提交，保留分支名称。

构建失败、合并冲突、工作区有未提交改动或构建期间远端更新时停止，不自动重试、不自动 stash、不强推。远端不支持原子推送或分支保护拒绝更新时，整次推送失败，不回退为逐分支推送。该入口需要远端允许推送 release/master；缺失分支时停止，不自动创建。推送成功后如本地或远端又发生变化，输出需要人工同步的错误，不重试写操作。

成功日志包含最终 master 提交。后续生产 OSS 发布仍通过原“后台管理系统-vue3”入口执行；本次新增菜单不触发生产发布。临时构建目录退出时删除。若进程被强制终止，应先确认任务已结束，再清理提示的 Git 锁文件。
